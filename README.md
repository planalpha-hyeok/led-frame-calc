# LED 프레임 파이프 계산기

LED 캐비넷 프레임(각파이프) 설치 위치를 계산하는 웹앱입니다. — 가이드삼정 김성혁

- 평면(매립) · ㄱ · ㄷ · 천장/바닥 · 기둥 감싸기 · 곡면(플렉시블/꺾음)
- 평면도 · 입면도 · 줄자 기준표 · 코너/깊이/간섭 자동 검사
- ㄷ은 중앙 벽부터 시공 → 옆 벽은 설치된 스크린 앞면 기준으로 측정
- 현장별 저장, 공유 링크, 인쇄·PDF
- 홈 화면 설치(PWA), 오프라인 동작

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 계산기 본체 (화면 + 계산 로직 전부) |
| `manifest.webmanifest` | 앱 설치 정보 (이름, 아이콘) |
| `sw.js` | 오프라인 캐시 |
| `icons/` | 앱 아이콘 |

## 배포
GitHub Pages: Settings → Pages → Branch `main` / `(root)` → Save.

## 수정 후 반영
`index.html`을 고치면 `sw.js`의 `CACHE` 이름 버전도 올려주세요(예: `led-frame-calc-v2.4`). 그래야 설치된 앱도 새 파일을 받습니다.
